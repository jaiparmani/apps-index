# Apps

One page to open everything I've built and actually run: the
[brain](https://github.com/jaiparmani/brain-store) ecosystem (which shares one
memory store instead of each app keeping its own copy of what it knows about
me), plus everything else — Portfolio, Meridian City, Learning Notes, Nexus Field.

Static HTML, no build step. Deployed with `wrangler deploy`.

Live at <https://apps.brain-store.workers.dev>.
